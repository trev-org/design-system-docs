Use badges for short, non-interactive metadata, such as a status, a category, or a count. If people can click it to filter or remove it, use a [tag](/components/tag) or `Chip` instead.

## Anatomy

1. **Container**: height 24px (20px at `sm`, 28px at `lg`), padding X `space.2` (`space.1-5` at `sm`, `space.3` at `lg`), radius `radius.full`, horizontal auto layout, gap `space.1` (`space.1-5` at `lg`).
2. **Status dot** (optional): 6px circle in the current text color.
3. **Label**: `typography.label.sm` (`label.md` at `lg`), one to two words, sentence case.

## Tones and appearances

Every tone comes in two appearances. **Subtle** (default) uses a tinted fill; **Outline** uses a border on a transparent background for lower emphasis in dense tables.

## States

Badges are static and have no hover, focus, or disabled states. To show that the labelled item is disabled, dim the item, not the badge.

## Props

<ResponseField name="tone" type='"neutral" | "brand" | "success" | "warning" | "danger" | "info"' default="neutral">

</ResponseField>

<ResponseField name="appearance" type='"subtle" | "outline"' default="subtle">
  Filled tint or outline.
</ResponseField>

<ResponseField name="size" type='"sm" | "md" | "lg"' default="md">
  Height and padding.
</ResponseField>

<ResponseField name="dot" type="boolean" default="false">
  Shows a leading status dot.
</ResponseField>

<ResponseField name="icon" type="ReactNode">
  A 12px icon in place of the dot.
</ResponseField>

<ResponseField name="children" type="ReactNode" required>
  The label. Keep it to one or two words.
</ResponseField>

## Examples

<CodeGroup>
```tsx Status
import { Badge } from "@lumen/react";

const statusTone = { active: "success", pending: "warning", failed: "danger" } as const;

export function StatusBadge({ status }: { status: keyof typeof statusTone }) {
  return (
    <Badge tone={statusTone[status]} dot>
      {status[0].toUpperCase() + status.slice(1)}
    </Badge>
  );
}
```
```tsx Count
import { Badge } from "@lumen/react";

<h2>
  Open issues <Badge size="sm" aria-label="12 open issues">12</Badge>
</h2>
```
</CodeGroup>

## Accessibility

- Badges render as `<span>` and are read inline with surrounding text.
- Color is never the only signal: the label always states the status in words.
- For counts, add an `aria-label` with context ("12 open issues") when the number alone is ambiguous.
- All tone pairings meet 4.5:1 text contrast in both modes (for example, brand 6.39:1 light, 7.91:1 dark).

## Usage
