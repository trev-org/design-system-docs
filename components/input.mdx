Use an input for short, free-form text such as names, emails, and search queries. For multiple lines, use `Textarea`. For a fixed set of options, use `Select`.

## Anatomy

1. **Label**: `typography.label.md`, `color.text.primary`. Always visible; required fields add a `color.text.danger` asterisk.
2. **Field container**: height 40px, padding X `space.3`, radius `radius.md`, border `border-width.thin` `color.border.strong`, fill `color.bg.surface`, shadow `shadow.xs`.
3. **Leading icon** (optional): 16px, `color.text.tertiary`.
4. **Value / placeholder**: `typography.body.md`; value `color.text.primary`, placeholder `color.text.tertiary`.
5. **Helper or error text**: `typography.caption.md`, `color.text.secondary` (or `color.text.danger` when invalid).

Gaps: label to field `space.1-5` (6px), field to helper `space.1-5` (6px).

## Props

<ResponseField name="label" type="string" required>
  Visible label. Use `hideLabel` to hide it visually while keeping it for screen readers.
</ResponseField>

<ResponseField name="size" type='"sm" | "md" | "lg"' default="md">
  Field height and text size.
</ResponseField>

<ResponseField name="helperText" type="ReactNode">
  Guidance shown below the field and linked with `aria-describedby`.
</ResponseField>

<ResponseField name="error" type="ReactNode">
  Error message. Sets `aria-invalid="true"` and replaces `helperText` while present.
</ResponseField>

<ResponseField name="iconStart" type="ReactNode">
  Decorative icon inside the leading edge of the field.
</ResponseField>

<ResponseField name="endAdornment" type="ReactNode">
  Content at the trailing edge, such as a unit ("kg") or a clear button.
</ResponseField>

<ResponseField name="required" type="boolean" default="false">
  Adds the asterisk and the native `required` attribute.
</ResponseField>

<ResponseField name="disabled" type="boolean" default="false">
  Disables the field.
</ResponseField>

<ResponseField name="readOnly" type="boolean" default="false">
  Value can be selected and copied but not changed.
</ResponseField>

<ResponseField name="hideLabel" type="boolean" default="false">
  Visually hides the label. Only use when context makes the purpose obvious, such as a search bar.
</ResponseField>

Also accepts every native `<input>` attribute (`type`, `name`, `value`, `onChange`, `autoComplete`, and so on).

## Examples

<CodeGroup>
```tsx Basic
import { Input } from "@lumen/react";

<Input label="Full name" name="name" autoComplete="name" required />
```
```tsx Validation
import { useState } from "react";
import { Input } from "@lumen/react";

export function EmailField() {
  const [value, setValue] = useState("");
  const invalid = value.length > 0 && !value.includes("@");
  return (
    <Input
      label="Work email"
      type="email"
      value={value}
      onChange={(e) => setValue(e.target.value)}
      helperText="We'll send a confirmation link."
      error={invalid ? "Enter a valid email, like name@company.com." : undefined}
    />
  );
}
```
```tsx Search
import { Input } from "@lumen/react";
import { SearchIcon } from "@lumen/icons";

<Input label="Search projects" hideLabel type="search" iconStart={<SearchIcon />} placeholder="Search…" />
```
</CodeGroup>

## Accessibility

- The label is a real `<label for>`, so clicking it focuses the field and screen readers announce it.
- Helper and error text are connected with `aria-describedby`; errors also set `aria-invalid="true"`.
- Placeholder text is **not** a label. It disappears on input and has lower contrast (4.55:1).
- Use the correct `type` and `autoComplete` so mobile keyboards and password managers work.
- The field border meets 3:1 non-text contrast (4.55:1 light, 3.74:1 dark).

## Usage

<Columns cols={2}>
  <Check>
    **Do** keep labels short and above the field. Put extra detail in helper text.
  </Check>
  <Warning>
    **Don't** use placeholder text as the only label.
  </Warning>
  <Check>
    **Do** size the field to the expected input: a ZIP code field can be narrower than an address field.
  </Check>
  <Warning>
    **Don't** validate on every keystroke. Validate on blur or on submit.
  </Warning>
</Columns>
