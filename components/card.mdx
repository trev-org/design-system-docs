Use a card to present a self-contained summary, such as a project, a plan, or a metric, that people can scan and act on.

On Android and iOS, the `media` slot and the `selected` state are in beta.

## Anatomy

1. **Container**: fill `color.bg.surface`, radius `radius.lg`, vertical auto layout, clips content.
2. **Media** (optional): full-bleed image or illustration, 16:9 or fixed 120px height.
3. **Header**: optional badge or eyebrow, title (`typography.heading.sm`, `color.text.primary`), description (`typography.body.sm`, `color.text.secondary`). Gap `space.2`.
4. **Body**: any content. Padding `space.6` (24px), or `space.4` for the compact density.
5. **Footer** (optional): actions aligned to the end, gap `space.2`, padding `space.4` / `space.6`, top border `color.border.subtle`.

### Interactive cards

When the whole card is a link or button, add `interactive`. On hover it lifts to `shadow.md` and the border strengthens to `color.border.strong`.

## Sizes and density

| Density | Body padding | Footer padding | Use for |
|---|---|---|---|
| `comfortable` (default) | `space.6` (24px) | `space.4` × `space.6` | Dashboards, marketing, settings |
| `compact` | `space.4` (16px) | `space.3` × `space.4` | Grids of many cards, sidebars |

Cards are fluid: they fill their grid column. Recommended minimum width is 240px.

## States

| State | Outlined | Elevated | Applies to |
|---|---|---|---|
| Default | `color.border.default` | `shadow.sm` | All |
| Hover | `color.border.strong` + `shadow.md` | `shadow.md` | Interactive only |
| Focus | 2px `color.border.focus` outline, 2px offset | same | Interactive only |
| Selected | 2px `color.border.brand` border, fill `color.bg.brand-subtle` | same | Selectable only |
| Disabled | 50% opacity, no hover | same | Interactive only |

## Props

<ResponseField name="variant" type='"outlined" | "elevated" | "filled"' default="outlined">
  Visual treatment.
</ResponseField>

<ResponseField name="density" type='"comfortable" | "compact"' default="comfortable">
  Internal padding.
</ResponseField>

<ResponseField name="title" type="ReactNode">
  Card heading, rendered as `h3` by default. Change with `titleAs`.
</ResponseField>

<ResponseField name="description" type="ReactNode">
  Supporting text below the title.
</ResponseField>

<ResponseField name="media" type="ReactNode">
  Full-bleed content above the header, usually an `<img>` with `alt` text.
</ResponseField>

<ResponseField name="footer" type="ReactNode">
  Actions rendered in the footer area.
</ResponseField>

<ResponseField name="interactive" type="boolean" default="false">
  Adds hover and focus styles. Combine with `asChild` to render the card as a link.
</ResponseField>

<ResponseField name="selected" type="boolean" default="false">
  Selected style for cards used as large radio options. Sets `aria-checked` when inside a `CardGroup` with `type="single"`.
</ResponseField>

<ResponseField name="titleAs" type='"h2" | "h3" | "h4"' default="h3">
  Heading level for the title so it fits the page outline.
</ResponseField>

```tsx Basic
</Card>
```

```tsx Selectable
import { Card, CardGroup } from "@lumen/react";

<CardGroup type="single" defaultValue="pro" aria-label="Plan">
  <Card value="starter" title="Starter" description="$0 / month" />
  <Card value="pro" title="Pro" description="$24 / seat / month" />
</CardGroup>
```

## Accessibility

- A plain card is a `<div>` with no role. Give its title a heading level that fits the page outline.
- An interactive card wraps the **whole** card in a single link or button. Don't nest other interactive elements inside it, as nested links are invalid and confusing for screen readers.
- If a card has several actions, keep the card non-interactive and put buttons in the footer.
- Selectable cards in a `CardGroup` use `role="radiogroup"` / `role="radio"` and arrow-key navigation.
