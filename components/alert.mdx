Use an alert to tell people about something that affects the page they're on: a system status, the result of an action, or a problem that needs attention. For brief confirmations that disappear on their own, use a `Toast`. For decisions that block progress, use a [modal](/components/modal).

| Platform | Status | Component | Package |

| Android | <Badge color="orange" size="sm">Beta</Badge> | `LumenAlert` | `com.lumen:compose` |
| iOS | <Badge color="gray" size="sm">Planned</Badge> | `LumenAlert` | `LumenUI` (Swift Package) |

Not yet available on iOS. Until it ships, use a native inline message styled with Lumen tokens.

## Anatomy

1. **Container**: horizontal auto layout, padding `space.4`, gap `space.3`, radius `radius.lg`, border `border-width.thin` in the tone's border color, fill in the tone's subtle background.
2. **Icon**: 20px, tone text color. Each tone has a fixed icon.
3. **Title**: `typography.label.md`, `color.text.primary`.
4. **Description**: `typography.body.sm`, `color.text.secondary`. Gap from title `space.1`.
5. **Actions** (optional): up to two text actions, `typography.label.md`, tone text color. Margin-top `space.2`.
6. **Dismiss button** (optional): 32px ghost icon button.

## Layouts

| Layout | Description |
|---|---|
| `inline` (default) | Sits in the content flow with rounded corners. |
| `banner` | Full width at the top of a page or panel, no radius, bottom border only. Use for app-wide notices. |

## States

Alerts are static. The dismiss button and action links have their own hover (`color.bg.muted` fill / underline) and focus (2px `color.border.focus` outline) states. Dismissing fades the alert out with `duration.normal` and `easing.exit`.

## Props

<ResponseField name="tone" type='"info" | "success" | "warning" | "danger"' default="info">
  Meaning, color, icon, and ARIA role.
</ResponseField>

<ResponseField name="title" type="ReactNode" required>
  A short summary of the message.
</ResponseField>

<ResponseField name="children" type="ReactNode">
  Description. Keep it to one or two sentences.
</ResponseField>

<ResponseField name="actions" type="ReactNode">
  Up to two `AlertAction` elements.
</ResponseField>

<ResponseField name="onDismiss" type="() => void">
  When set, shows a dismiss button. Persist dismissal yourself if the alert shouldn't return.
</ResponseField>

<ResponseField name="layout" type='"inline" | "banner"' default="inline">
  Inline card or full-width banner.
</ResponseField>

<ResponseField name="icon" type="ReactNode | false">
  Override the tone's icon, or pass `false` to hide it.
</ResponseField>

## Example

```tsx
import { Alert, AlertAction } from "@lumen/react";

export function TrialAlert({ daysLeft, onDismiss }: { daysLeft: number; onDismiss: () => void }) {
  return (
    <Alert
      tone="warning"
      title={`Your trial ends in ${daysLeft} days`}
      onDismiss={onDismiss}
      actions={
        <>
          <AlertAction href="/billing">Add payment method</AlertAction>
          <AlertAction onClick={onDismiss}>Remind me later</AlertAction>
        </>
      }
    >
      Add a payment method to keep access to Pro features and your project history.
    </Alert>
  );
}
```

## Accessibility

- Info, success, and warning alerts use `role="status"` (polite). Danger alerts use `role="alert"` (assertive), so use them sparingly.
- Alerts present on page load aren't announced; that's expected. Alerts inserted after an action are announced automatically.
- Each tone has a distinct icon, so meaning doesn't rely on color alone.
- Text contrast on every subtle background is at least 4.84:1 (warning, light mode).
- The dismiss button has `aria-label="Dismiss"`. After dismissal, focus moves to the next logical element.
