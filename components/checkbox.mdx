Use checkboxes for independent choices where any number can be selected, and for single opt-ins such as accepting terms. For a setting that takes effect immediately, use a [switch](/components/switch).

## Anatomy

1. **Box**: 20 × 20px (16px at `sm`), radius `radius.sm`, border `border-width.thin` `color.border.strong`, fill `color.bg.surface`.
2. **Indicator**: check or dash glyph, `color.text.on-brand`, on a `color.bg.brand` fill.
3. **Label**: `typography.body.md` (`body.sm` at `sm`), `color.text.primary`. Gap to box: `space.2`.
4. **Description** (optional): `typography.body.sm`, `color.text.secondary`.

|---|---|---|
| Unchecked | `color.bg.surface` | `color.border.strong` (hover: `color.text.secondary`) |

| Error | `color.bg.surface` | `color.border.danger` |
| Disabled | `color.bg.muted` | `color.border.default` |
| Focus | unchanged | plus 2px `color.border.focus` outline, 2px offset |

## Props

<ResponseField name="label" type="ReactNode" required>
  Visible label. Clicking it toggles the checkbox.
</ResponseField>

<ResponseField name="description" type="ReactNode">
  Secondary text below the label, linked with `aria-describedby`.
</ResponseField>

<ResponseField name="checked" type='boolean | "indeterminate"'>
  Controlled state. Use `"indeterminate"` for a parent whose children are partially selected.
</ResponseField>

<ResponseField name="defaultChecked" type="boolean" default="false">
  Initial state when uncontrolled.
</ResponseField>

<ResponseField name="onCheckedChange" type='(checked: boolean | "indeterminate") => void'>
  Called when the user toggles the checkbox.
</ResponseField>

<ResponseField name="size" type='"sm" | "md"' default="md">
  Box and label size.
</ResponseField>

<ResponseField name="invalid" type="boolean" default="false">
  Shows the error border and sets `aria-invalid`.
</ResponseField>

<ResponseField name="disabled" type="boolean" default="false">
  Disables the checkbox.
</ResponseField>

## Examples

<CodeGroup>
```tsx Single
import { Checkbox } from "@lumen/react";

<Checkbox label="I agree to the terms of service" required />
```
```tsx Group with select all
import { useState } from "react";
import { Checkbox, CheckboxGroup } from "@lumen/react";

const options = ["Product updates", "Weekly digest", "Security alerts"];

export function NotificationPrefs() {
  const [selected, setSelected] = useState<string[]>(["Security alerts"]);
  const all = selected.length === options.length;
  return (
    <CheckboxGroup legend="Email notifications" value={selected} onValueChange={setSelected}>
      <Checkbox
        label="Select all"
        checked={all ? true : selected.length ? "indeterminate" : false}
        onCheckedChange={() => setSelected(all ? [] : options)}
      />
      {options.map((o) => (
        <Checkbox key={o} value={o} label={o} />
      ))}
    </CheckboxGroup>
  );
}
```
</CodeGroup>

## Accessibility

- Built on a native `<input type="checkbox">`, so <kbd>Space</kbd> toggles it and it works in forms without JavaScript.
- Groups render as a `<fieldset>` with a `<legend>` so the group name is announced.
- Indeterminate sets `aria-checked="mixed"`.
- The 20px box sits inside a 24px minimum hit area; the label is also clickable.
