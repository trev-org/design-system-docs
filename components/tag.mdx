Use tags for values that people pick, filter by, or remove, such as active filters or selected recipients. Unlike a [badge](/components/badge), a tag can be removed or clicked. For static status labels, use a badge.

## Anatomy

1. **Container**: height 32px (24px at `sm`), padding left `space.3` and right `space.2` (`space.2` and `space.1-5` at `sm`), radius `radius.md`, horizontal auto layout, gap `space.1`.
2. **Leading icon** (optional): swappable icon before the label.
3. **Label**: `typography.label.md` (`label.sm` at `sm`), sentence case.
4. **Remove button** (optional, shown by default): 20px (16px at `sm`) hit area with radius `radius.sm`, holding a 14px (12px at `sm`) close icon in `color.text.secondary`.

## Props

<ResponseField name="tone" type='"neutral" | "brand"' default="neutral">
  Color of the tag. Maps to the Figma property `Tone`.
</ResponseField>

<ResponseField name="size" type='"sm" | "md"' default="md">
  Height, padding, and text size. Maps to the Figma property `Size`.
</ResponseField>

<ResponseField name="removable" type="boolean" default="true">
  Shows the remove button. Maps to the Figma property `Removable`.
</ResponseField>

<ResponseField name="leadingIcon" type="boolean" default="false">
  Shows an icon before the label. Maps to the Figma property `Leading icon`.
</ResponseField>

<ResponseField name="disabled" type="boolean" default="false">
  Prevents interaction. Maps to the `Disabled` value of the Figma property `State`.
</ResponseField>

<ResponseField name="children" type="ReactNode" required>
  The label. Maps to the Figma text property `Label`.
</ResponseField>

## Accessibility

- The remove button needs an `aria-label` that names the tag it removes ("Remove Design"), not just "Remove".
- Color is never the only signal: the label always states the value in words.
