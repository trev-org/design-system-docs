## What's inside

Lumen gives product teams a shared vocabulary. Designers pick from the same tokens, text styles, and component variants that engineers import from `@lumen/react`.

```tsx App.tsx
import "@lumen/tokens/lumen.css";

export default function App() {
  return (
    <LumenProvider theme="system">
      <Button variant="primary">Create project</Button>
      <Badge tone="success" dot>Live</Badge>
    </LumenProvider>
  );
}
```

## How Lumen is organized

<Columns cols={3}>
  <Card title="Tokens" icon="blend">
    The single source of truth lives in `figma/tokens` as W3C design tokens. A build script turns them into CSS variables and these docs.
  </Card>
  <Card title="Components" icon="box">
    React components consume semantic tokens only, so a theme change never needs a component change.
  </Card>
  <Card title="Figma" icon="pen-tool">
    The same tokens become Figma variables with Light and Dark modes, and the component spec maps every layer to a token.
  </Card>
</Columns>

<Tip>
  New to Lumen? Read the [design principles](/get-started/principles) first. They explain the decisions behind every token and component.
</Tip>
