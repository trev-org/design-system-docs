## Token naming

Tokens are named from general to specific, separated by dots in JSON and dashes in CSS.

| Layer | Pattern | Example | CSS variable |
|---|---|---|---|
| Primitive | `category.scale.step` | `color.brand.600` | `--lumen-color-brand-600` |
| Semantic | `category.role.variant` | `color.bg.brand-hover` | `--lumen-color-bg-brand-hover` |
| Type style | `typography.group.size` | `typography.heading.lg` | `--lumen-typography-heading-lg` |
| Dimension | `category.step` | `space.4`, `radius.md` | `--lumen-space-4`, `--lumen-radius-md` |

<Info>
  Components reference **semantic** tokens only. Primitives exist so semantic tokens have something to point at, and so you can build one-off illustrations.
</Info>
